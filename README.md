This project serves as a practical exercise in building a RESTful API using Jakarta EE technologies, specifically focusing on Servlets. It aims to provide a foundational understanding of handling HTTP requests and responses within the Jakarta EE framework.

The application is deployed on Apache Tomcat

Features
Implementation of RESTful endpoints using Jakarta Servlets.
Demonstrates handling of HTTP methods: GET, POST, PUT, DELETE.
Structured project layout adhering to Jakarta EE conventions.
Utilizes Maven for project management and build processes
